## Detailed Description (max 16,000 characters)

**Never Lose Track of Your Job Applications Again!**

JobTracker is your personal job application assistant that automatically tracks every job you apply to on LinkedIn and Naukri. Say goodbye to spreadsheets and manual tracking!

**✨ Key Features:**

🎯 **Automatic Tracking**
- Automatically detects when you click "Apply" or "Easy Apply" on LinkedIn
- Tracks applications on Naukri.com
- No manual data entry required

📊 **Personal Dashboard**
- View all your applications in one place
- Track application status and dates
- Access from any device via web dashboard

🔔 **Smart Notifications**
- Get notified when jobs are successfully tracked
- Reminder for external applications
- Badge notifications for pending confirmations

🔒 **Privacy & Security**
- Your data is stored securely
- No data sharing with third parties
- Full control over your information

💼 **Supported Platforms:**
- LinkedIn (Easy Apply & External Apply)
- Naukri.com

**How It Works:**

1. Install the extension
2. Click "Open Dashboard" to create your account
3. Browse jobs on LinkedIn or Naukri
4. Click "Apply" as usual
5. JobTracker automatically saves the details!

**Perfect For:**
- Job seekers managing multiple applications
- Anyone tired of manual tracking
- Professionals who want to stay organized

**Privacy Policy:**
We respect your privacy. JobTracker only tracks job applications you explicitly apply to. We never access your personal messages, emails, or other LinkedIn/Naukri data.

**Support:**
Need help? Contact us through the feedback form in the extension or visit our website.

## Single Purpose Description
This extension tracks job applications on LinkedIn and Naukri, helping users organize their job search by automatically saving application details to a personal dashboard.

## Permission Justifications

**storage**
- Required to save authentication tokens and job application data locally
- Stores user preferences and settings

**notifications**
- Shows success/error notifications when tracking jobs
- Alerts users about pending application confirmations

**host_permissions (linkedin.com, naukri.com)**
- Required to detect "Apply" button clicks on job pages
- Extracts job details (title, company, location) from the page
- Only activates on job-related pages

## Remote Code
No remote code is used. All code is bundled in the extension. The extension does not execute any code from remote sources.

## Data Usage Disclosure
- **Authentication**: Email and password for user account (stored securely with bcrypt hashing)
- **Personal Data**: Job application details (company name, job title, location, application date, job URL)
- **Website Content**: Job page URLs from LinkedIn and Naukri
- **Usage**: All data is stored on secure backend servers and used only for displaying in user's personal dashboard
- **Not sold to third parties**: We never sell, rent, or share your data with advertisers or data brokers
- **Not used for purposes unrelated to core functionality**: Data is only used for job application tracking
- **Limited Use Compliance**: The use of information received from Google APIs adheres to Chrome Web Store User Data Policy, including the Limited Use requirements
